# Security reports

Use the repository's Security tab, then Report a vulnerability, to send a private report. Include steps to reproduce the issue and its likely effect. Do not include live credentials or other people's private data.

If private reporting is unavailable, use GitHub Support to ask for a private reporting route. Do not disclose an unpatched issue in a public issue.

Maintainers review reports on a best-effort basis. There is no guaranteed response time. Fixes target the current `main` branch; old snapshots have no separate support policy.
