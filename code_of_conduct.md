# Code of conduct

Be curious, respectful, and direct. Help people learn. Review the work and explain your reasoning.

Do not harass, threaten, discriminate against, or publish private information about another person. Do not use sexual content or personal attacks in project spaces.

These rules apply to issues, pull requests, discussions, and other project spaces. Maintainers can remove content, close a discussion, or limit access when needed. Explain the reason when it is safe to do so.

Use GitHub's private Report content or Report abuse option to report harmful content. Do not post sensitive details in a public issue. A continuing RPI maintainer must add a project-specific private contact during handoff.
